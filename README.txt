COFFEE SHOP APPLICATION

This is a simple C# Console Application for the Software Construction
Lab #10 Version Control task.

Files:
- Program.cs: Starts the application.
- CoffeeShop.cs: Runs the ordering process.
- Menu.cs: Displays menu items and prices.
- Order.cs: Stores order details and calculates the total.
- PaymentProcessor.cs: Displays payment confirmation.

To open:
1. Open Visual Studio.
2. Select Open a project or solution.
3. Select CoffeeShop.csproj.
4. Press Ctrl + F5 to run without debugging.

The application is a starter project. You can use this folder for the
Git and GitHub steps in the lab.
